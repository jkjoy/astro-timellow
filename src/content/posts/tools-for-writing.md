写作工具越复杂，我越容易把时间花在调整工具上。现在的流程只保留三个步骤：记录、整理、发布。

## 随时记录

临时想法先进入收集箱。它可以是一句话，也可以只是一个值得继续追问的问题。这个阶段不分类，不排版。

## 在纯文本中整理

真正开始写作时，我会创建一个 Markdown 文件。纯文本没有多余的按钮，标题、列表、引用和代码已经足够覆盖绝大多数表达。

```md
## 一个小标题

先写清楚问题，再寻找漂亮的句子。
```

## 用版本记录变化

Git 不只是开发工具。它能保存每次修改，也让我放心删掉那些不再必要的段落。文章完成后，推送代码就会触发自动构建和部署。

流程足够短，注意力才有机会停留在真正重要的事情上。
